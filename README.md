# BookNook - A Small Online Library (Client)

**Live Site URL:** [https://b14-a08-book-nook-client.vercel.app/](https://b14-a08-book-nook-client.vercel.app/)

BookNook is a modern, full-stack online library application where users can explore, add, and borrow books. This repository contains the **Frontend (Client)** code built with Next.js (App Router), TypeScript, and Tailwind CSS.

## 🔥 Key Features of the Website
- **Secure Authentication:** Seamless login and registration using Email/Password and Google OAuth, powered by BetterAuth.
- **Comprehensive Book Management:** Users can add new books with ImgBB image upload, edit their existing books, and delete them using a custom confirmation modal.
- **Interactive Borrow System:** Logged-in users can borrow books for 7 days. Real-time updates for available copies and a "Return Book" functionality in the My Borrows dashboard.
- **Dynamic Home Page:** Features a Swiper.js hero slider, a dynamic "New Arrivals" section with live category filtering, and a "Featured Authors" spotlight section.
- **Beautiful & Responsive UI:** A carefully balanced color palette (Forest Green, Cream, and Terracotta) with a fully functional Dark/Light mode toggle and mobile-friendly navigation.

## 🛠️ Tech Stack
- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS, Shadcn UI
- **Authentication:** BetterAuth (Client-side)
- **Carousel/Slider:** Swiper.js
- **Icons:** Lucide React
- **Image Hosting:** ImgBB API
